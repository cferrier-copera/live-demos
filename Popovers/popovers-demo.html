Accessibility Features
  • Reads popover on trigger focus
  • Hidden live region for screen reader announcements on hover (aria-live="assertive")
  • aria-label on trigger buttons for context
  • aria-describedby linking trigger to popover content
  • aria-expanded state management (reflects open/closed state)
  • aria-label on close button for clear dismissal action
  • aria-hidden on decorative "?" icon
  • Keyboard navigation support (Tab, Escape)
  • Close button for manual dismissal
  • Hover behavior with automatic announcements
  • Focus management (closes when focus leaves trigger and popover)
